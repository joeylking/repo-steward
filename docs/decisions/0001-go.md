# 1. Go for both projects

Decision: implement the runtime and Repo Steward in Go.

Why: the work is deterministic control, persistence, process supervision,
and container orchestration, which Go serves well, and it matches the
author's experience. `os.Root` gives operating-system-level containment
for file tools. The Go module ecosystem is also the first target, so the
toolchain's own commands do the manifest work.

Alternatives: Python for its agent libraries; TypeScript for provider SDKs.

Tradeoffs: fewer ready-made agent components, which is irrelevant because
the point is the controls, not the loop.

Revisit when: never for the runtime; a second ecosystem does not change
the language.
